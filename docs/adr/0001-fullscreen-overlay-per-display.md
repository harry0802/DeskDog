# 每個螢幕一個全螢幕透明覆蓋層，而不是跟著狗移動的小視窗

狗狗畫在每個螢幕各一個全螢幕、透明、置頂的覆蓋視窗中，依游標是否命中狗狗身體動態切換 `setIgnoreMouseEvents(…, { forward: true })` 以達成點擊穿透。我們放棄「小視窗 + 每幀 `setPosition`」，因為抱起、下落、傾斜、拉伸與泡泡翻邊在畫布座標中都只是數學，而在 Windows 上高頻移動視窗容易抖動，泡泡也會被視窗邊界裁切。

## Consequences

- 跨螢幕拖拽需在 Drop 時把狗狗交給所在螢幕的覆蓋層。
- 命中測試必須精準到狗狗身體，否則透明區域會擋住使用者操作。
