# 分層部件 + 程序動畫，而不是逐格 sprite 或 Spine

狗狗由約 15 張同畫布、未裁切的分層 Part PNG 組成（側面視角、可水平翻轉），所有動畫——呼吸、眨眼、搖尾、跳、趴、被抱起時腿下垂與傾斜、落地壓扁回彈——都在 PixiJS 中以程式計算（Container 旋轉、`MeshRope` 尾巴與腿、`MeshPlane` 身體變形）。我們放棄逐格 sprite（1～2 週內畫不完，且無法即時反應拖拽速度）、Spine（付費且需編輯器工作流）、Live2D（偏正面臉部表情）與 AI 生成逐格（幀間一致性不穩）。

## Consequences

- 素材以 PSD 交付，由腳本拆層並產出各 Part 的 Pivot 座標；開發初期用程式繪製的佔位 Part。
- 換成正面或 3/4 視角需要重做大部分動畫程式。
- 分層結構可直接沿用到未來的 Spine 升級。
